# luci-app-cf-dns-speedtest — Cloudflare DNS IP optimization plugin

A Cloudflare DNS optimization plugin for OpenWrt / iStoreOS. It runs
[XIU2/CloudflareSpeedTest](https://github.com/XIU2/CloudflareSpeedTest) to find
a better Cloudflare Anycast IPv4 address, then serves only the configured
domains through a dedicated mosdns bypass instance.

## Design boundaries

- Does not replace dnsmasq's default upstream.
- Does not disable or bypass existing DNS services such as AdGuardHome or SmartDNS.
- Only domains in the configured list are forwarded to this plugin's mosdns port.
- If a speed test fails, the last successful IP and DNS configuration are kept.

## Changes in v1.1.0

- Fixed the scheduled task not being written to crontab.
- Precisely tracks and cleans up the dnsmasq split-routing rules owned by this
  plugin; changing the port no longer leaves stale rules behind.
- Hard caps on log and diagnostic output to avoid filling up flash over time.
- Added test stop, last-test time, and scheduled-task status.
- Added validation for parameter ranges, test URL, and IPv4 results.
- A failed test no longer overwrites the previous result and attempts to
  restore the last working DNS configuration.
- Fixed LuCI Chinese garbled text; optimized status cards and the result
  table on narrow screens.

## Compatibility

- Tested: iStoreOS 24.10.8, x86_64, Linux 6.6.144.
- Architecture-independent: the speed test runs via the `cdnspeedtest`
  package, which is compiled from upstream source for the target.
- Dependencies: `luci-base`, `mosdns`, `cdnspeedtest`.

## Installation

```sh
opkg install ./luci-app-cf-dns-speedtest_1.1.0-2_all.ipk
```

Upgrades preserve `/etc/config/cf_dns_speedtest`. After installation, go to
"Services → Cloudflare DNS Speedtest", save the settings and click
"Apply DNS configuration".

## Files and services

- `/etc/config/cf_dns_speedtest`: UCI configuration.
- `/usr/bin/cf-dns-speedtest`: `start|run|stop|apply|status|ui`.
- `/var/lib/cf-dns-speedtest/`: test results and the generated bypass mosdns config.
- `/etc/init.d/cf-dns-speedtest`: the dedicated mosdns instance.
